# One compact left slot, with no loading spinner or wider island

The user supplied screenshots and rejected the 42pt extension and separate blue
loading cue. This L2 correction restores the original compact frame and camera
anchor. Delete the extra width, trailing shell crop and compensating canvas
plumbing. Keep the existing leading crop for the legacy Left side Off setting.
A selected pet enables that original left lane; turning the pet Off restores
the stored choice. Weekly remains at its original right-wing coordinate.

Center one 26pt slot in the old 46pt lane, at the old icon's 23pt center. Pet,
real five-hour quota and completed check have identical container rectangles.
The full native pet cell is smaller than the container and constrained by the
existing compact stage insets; quota remains 22pt with the number inside it.
No blue running ring is constructed. Running uses authored work animation and
the enclosing button's truthful state label. Only actual five-hour data adds a
quota phase; only actual completed presentation state adds a check phase.

Each phase stays fully visible for 4.5 seconds, then crossfades over 0.35 seconds.
Native opacity animations run at a bounded compositor request of 30Hz. One
one-shot timer wakes at hold/fade boundaries (roughly four wakes per 9.7-second
two-item cycle). No frame timer, SwiftUI state cadence, panel resize or additional
window is used. Value and clock updates do not replace that timer or restart the
hold. Only a change to available phase identities restarts the phase schedule.
Inactive artwork is hidden, its native sprite playback is stopped, and the quota
phase uses static original ring/wave pixels to avoid invisible effect work.
Occlusion, hide, window/superview detachment cancel the timer and all fades; the
elapsed cadence pauses and resumes when visible. Child pet lifecycle retains its
existing authored playback/event ledger.

App animation off or system Reduce Motion disables both fades and pet motion.
Use a static five-hour value when present, otherwise an actual completed check,
otherwise the selected pet's static pose. The existing compact button always
exposes task state and every actual quota in its accessibility label; add the
same text as a native help tooltip. Click and hover keep their existing routes
to task/details, including quota/state that cannot all fit visually in one
static slot. No setting keys, defaults, library files, project order or read
receipts change. The separate expanded-stage-removal revision owns detail-card
height and artwork; this revision keeps its compact-header integration seam.

Rejected: hiding the old extension with an asymmetrical canvas; a separate
spinner slot; falsifying missing quota; rapid quota flashes; animating the
hidden pet or scheduling per frame; treating render images as animation proof.

PET-COMPACT-003 explicitly supersedes the earlier 42pt/separate-slot tests.
Their guards are retained and adapted to the requested original geometry,
same-rect indicators, true phase availability and old Off restoration. Native
cadence guards additionally check stable timers/playback through reconfigure,
real crossfades, hidden pet inactivity and stop/resume/detach. Synthetic and
explicit local-collection renders remain outside Git. Full verification and
