# Recover a refused conversation handoff

Use a localized native alert with explicit retry, open Codex and close actions.
Separate invalid identifiers, an unavailable current Codex app and a refused
URL handoff. An accepted URL only means the system accepted the handoff.
Capture the exact completion at the first click and compare it again after any
retry before writing an existing local opening receipt. Running, changed or
missing completions cannot receive that old acknowledgement. App activation and
cancellation never acknowledge a conversation.

Rejected: automatic app fallback, automatic retries, claiming that the target
was selected or read, and changing notch geometry for an inline error. No
conversation text, links or identifiers are shown in the alert or newly stored.
Real alert focus, VoiceOver, actual app handoff and notch geometry require
hardware confirmation.
