# Search the existing recent snapshot in a separate window

The native key window is opened explicitly from the app menu or fallback menu.
It filters the same ordered snapshot after the user's 0–20 limit, matching only
already available titles and project labels. A status picker reads current row
attention. It never changes compact state or marks a result read until the user
opens it through the existing navigator. Closing destroys the view and its
in-memory query. A zero limit hides the entry and closes an open search.

Rejected: an input on the non-key notch panel, archive/message search, saved
queries, and querying extra metadata on each keystroke. IME, focus, accessibility
and physical notch behavior remain pending real hardware verification.
