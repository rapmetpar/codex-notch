# CodexNotch 0.2.6

- **Conversation read state:** Reading a conversation in the native Codex client updates its state in the island. Opening a conversation from the island still acknowledges it locally.
- **Completion indicator:** Refreshing task metadata no longer replays an old completion check. Reading the answer clears its completion indicator.
- **Expanded layout:** Quota, reset controls and recent conversations sit closer together, with less unused vertical space. Project grouping, scrolling and footer controls remain available.

This is the first release of the personal fork with its own update signing key. If you are using an upstream build, download and install this version manually once; subsequent updates can be checked in Settings. To keep your settings and imported pets, replace only the app and leave its data in place.

Downloads are for Apple Silicon on macOS 14 or later. The app is not notarized by Apple. See the [installation guide](https://github.com/rapmetpar/codex-notch/blob/v0.2.6/README.md#install).
